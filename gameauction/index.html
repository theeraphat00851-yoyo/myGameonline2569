ขั้นที่ 1 — ตั้งค่าห้องประมูล

สร้างห้องประมูลใหม่

พอถึงข้อที่กำหนด ผู้เล่นครึ่งบนของตารางคะแนน ณ ตอนนั้นจะถูกกันไม่ให้ประมูลข้อนั้นชั่วคราว เปิดโอกาสให้คนตามหลังไล่คะแนนได้ (ต้องมีผู้เล่นอย่างน้อย 3 คนจึงจะเริ่มทำงาน)
คนที่ชนะการประมูลข้อหนึ่งจะถูกกันไม่ให้ประมูลได้อีกในอีก N ข้อถัดไป ช่วยกระจายโอกาสไม่ให้คนเดิมชนะรวด
⚠ ค่านี้มากกว่าหรือเท่ากับจำนวนคำถามที่มีอยู่ตอนนี้ — ผู้ชนะข้อแรกๆ อาจไม่ได้ประมูลอีกเลยตลอดเกม
ขั้นที่ 2 — นำเข้าโจทย์คำถาม
ยังไม่ได้เลือกไฟล์ — ดาวน์โหลดไฟล์ตัวอย่าง CSV หรือ ไฟล์ตัวอย่าง Excel (.xlsx) — ดูตัวอย่างรูปแบบไฟล์
คำถามตัวเลือก1ตัวเลือก2ตัวเลือก3ตัวเลือก4เฉลยแต้ม
1+1 เท่ากับเท่าไหร่1234220
เมืองหลวงของประเทศไทยคือเชียงใหม่ภูเก็ตกรุงเทพมหานครขอนแก่น3(ว่างได้)
แถวแรกต้องเป็นหัวคอลัมน์ตามชื่อด้านบนพอดี · เฉลย ใส่เป็นเลข 1-4 ระบุว่าตัวเลือกไหนถูก (ไม่ใช่ข้อความคำตอบ) · แต้ม เว้นว่างได้ถ้าอยากให้ระบบสุ่มคะแนนให้เอง
พบคำถามทั้งหมด 0 ข้อ — แก้ไข/ลบรายข้อได้ด้านล่าง
↩️ กลับเข้าคุมห้องเดิม
ถ้าหน้าจอครูรีเฟรชหรือปิดไปกลางเกม ใส่รหัสห้องเดิมเพื่อกลับเข้าไปคุมต่อได้ (ไม่ต้องสร้างห้องใหม่)
ตั้งค่า Firebase (ทำครั้งเดียว)
ใส่ค่า Firebase config ของคุณในไฟล์นี้ก่อนใช้งานจริง (ดูวิธีตั้งค่าแบบละเอียดในคู่มือที่แนบมา) หากยังไม่ได้ใส่ ระบบจะเตือนตรงนี้
⚠ ยังไม่ได้เชื่อมต่อ Firebase
🗑️ ล้างห้องเดิม
ใส่รหัสห้องที่ต้องการลบข้อมูลออกจาก Firebase ทั้งหมด (ใช้เมื่อทดสอบซ้ำ หรือห้องเก่าไม่ได้ใช้แล้ว) การลบนี้ย้อนกลับไม่ได้
🗑️ ลบห้องทั้งหมด
ลบห้องทุกห้องที่เคยสร้างไว้ทั้งหมดออกจาก Firebase ในครั้งเดียว (ใช้เมื่อต้องการล้างข้อมูลทดสอบทั้งหมด หรือเริ่มต้นใหม่) การลบนี้ย้อนกลับไม่ได้และมีผลกับห้องของทุกคนที่ใช้ฐานข้อมูลนี้ร่วมกัน
